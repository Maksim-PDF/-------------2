# Приложение "Ресторан: Расчет чека"

## Описание
MVP-проект на Python для автоматизации расчета стоимости заказа в ресторане. 
Программа позволяет выбрать столик, добавить блюда из меню, автоматически применяет скидку (от 3-х блюд), рассчитывает время ожидания и сохраняет результат в Excel и базу данных SQLite.

## Стек технологий
* Python 3.10+
* Tkinter (Графический интерфейс)
* Openpyxl (Экспорт в Excel)
* SQLite3 (База данных)
* Pytest (Тестирование)

## Инструкция по запуску
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите программу: `python main.py`
4. Для запуска тестов: `pytest`

## Справка
* При заказе от 3-х блюд автоматически применяется скидка 10%.
* Время ожидания рассчитывается по самому долго готовящемуся блюду.
